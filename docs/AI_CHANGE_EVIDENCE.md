# AI change review evidence

For changes affecting AI behavior, include the user outcome, simplest baseline, evidence provenance, permissions/data boundaries, budget/timeout, failure behavior, acceptance and negative tests, and observed results with denominators. Report errors and abstentions. Compare reviewer effort and cost per accepted result; token volume is a resource metric, not a measure of human value.

Record what remains unknown and how to roll back. Distinguish a branch, merged code, deployment and user validation. This checklist supports existing review policy; it does not ratify a new corporate constitution or grant merge/deployment authority.
