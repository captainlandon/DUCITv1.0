# ADR-05: What data may power proactive Now cards?

**Status:** Open.

## Decision evidence needed

Purpose, sensitivity, user benefit, interruption burden,
revocation/deletion (Dossier v1.0, section 12).

## Where this lands today

No Now surface exists in this scaffold. When it is built, it must follow
Verbal Reference Implementation v1.0 section 9 (salience/interruption
classes S0-S4) and Inner Workings & Data Flow Architecture v1.1 section
15.2 (Now Cards are architecture-derived, never manually curated, and
degrade to a permission prompt rather than empty/fabricated content).
